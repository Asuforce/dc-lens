DC Lens

選択制DCとiDeCoの比較シミュレータ

入力内容は送信・保存されません。計算はブラウザ内で完結します。

比較は判断の補助です。加入資格や勤務先の規程は別途ご確認ください。

条件を入力

すべての金額は円単位です。月給を省略すると年収と賞与から推定します。

この試算について

計算方法

簡易モードでは社会保険の等級に拠出差が即時反映されると仮定します。生涯差には退職時資産差を一度だけ加算します。

制度データ出典

計算結果の「計算根拠」から各制度の一次資料と検証日を確認できます。

FAQ・未対応項目

加入資格、拠出上限、既存資産の移換、受取時課税、詳細な随時改定は未対応です。初期運用資産とインフレ率は比較に含まれません。

プライバシー

入力値を送信、保存、URLへの埋め込み、ログ記録しません。

免責事項

個別の金融・税務・年金の助言ではありません。利回りは仮定であり将来を保証しません。資産額は税引前評価額です。

問い合わせ・問題報告

GitHub Issuesへお寄せください。個人情報は記載しないでください。
