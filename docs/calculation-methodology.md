# 計算方法

実装に合わせて更新する。現在は方針のみ。

## 原則

- 金額は整数円。計算用の丸めと表示用の丸めを分ける。
- 年間の手取り差、運用資産差、老齢厚生年金差、現在価値差は別々に集計し、重複して加算しない。
- 運用資産の残高差を毎年加算しない。保険料の節約分は現金メリットとして計上し、再投資分を二重に数えない。
- 損益分岐年齢は、定義した累積差が0を横切る時点。横切らなければ `null`。

## 運用(実装済み: `src/engine/investment.ts`)

月次で次の順に処理し、各段階で整数円に丸める(四捨五入)。

1. 月初に拠出する。
2. 信託報酬控除前の想定利回りで運用する。月次成長率は `(1 + r)^(1/12) - 1`。
3. 運用後の残高に、月次の信託報酬を課す。月次コスト率は `1 - (1 - c)^(1/12)`。年率 c は12か月で `1 - c` に複利で一致する。
4. 固定費を差し引く。残高を超える分は課さない(残高は0未満にならない)。

両制度に同じ想定利回りを使い、信託報酬と固定費だけを別々に与える。

## 社会保険料(`src/engine/social-insurance.ts`)

- 健康保険と厚生年金は別々の等級表で、月額報酬から等級を決める(下限以上、上限未満)。
- 本人負担は保険料額の折半。給与から控除する場合の端数処理に従い、50銭以下は切り捨て、50銭を超えれば切り上げる。整数演算で厳密に行う。
- 健康保険の料率は、都道府県別の健康保険料率と子ども・子育て支援金率の合計に、40歳以上65歳未満は介護保険料率を加える。
- 標準賞与額は賞与の1,000円未満を切り捨てる。厚生年金は支給月ごとに月150万円、健康保険は年間累計573万円を上限とする。

## 税(`src/engine/tax.ts`)

- 給与所得 = 給与収入 − 給与所得控除。課税所得 = 給与所得 − 社会保険料控除 − 小規模企業共済等掛金控除 − 基礎控除。1,000円未満を切り捨てる。
- 所得税 = 課税所得 × 税率 − 控除額。これに復興特別所得税(令和9年分以降は復興と防衛の合計)を加え、合計の100円未満を切り捨てる。
- 選択制DCの事業主掛金は給与収入から除かれ、iDeCoの個人掛金は小規模企業共済等掛金控除として扱う。選択制DCは給与収入が減るので給与所得控除も小さくなり、掛金分だけ課税所得が減るiDeCoとは差が出る。

## 老齢厚生年金(`src/engine/pension.ts`)

年ごとの加算額 = (標準報酬月額 × 12 + 標準賞与額) × 5.481/1000。この年の標準報酬が両制度で同じなら加算額の差はゼロ。受給期間は受給開始年齢から受給終了年齢の手前まで。

## 生涯比較(`src/engine/simulate.ts`)

- 差はすべて「選択制DC − iDeCo」。正は選択制DCが有利。
- 累積差 = 手取りの差 + 年金受給額の差 + 退職時の運用資産残高の差(1回だけ)。残高差は毎年加算しない。
- 現在価値は割引率で割り引く。名目と現在価値は別の系列。
- 損益分岐年齢は、選択した評価基準の累積差が符号を変える、または0に達する最初の年齢。なければ `null`。
# 既存資産の移換

継続側は既存資産を退職まで月次運用する。移換側は最初に手数料を控除し、残高をゼロ未満にしない。移換期間中は運用と手数料を停止し、残りの期間を月次運用する。差額は移換側から継続側を引き、退職時点から割引いた現在価値も別に示す。新規掛金や社会保険料は含めない。

```text
既存資産 → 手数料控除 → 運用停止 → 月次運用 → 税引前残高
```
