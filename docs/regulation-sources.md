# 制度データの出典

各データセットは `src/regulations/data/<year>/` に JSON として置き、`meta` に `version`、`effectiveFrom`、`effectiveTo`、`sourceName`、`sourceUrl`、`verifiedAt`、`status` を持つ。

## 運用規則

- 数値は一次資料(日本年金機構、厚生労働省、国税庁、全国健康保険協会、各健康保険組合、国民年金基金連合会)から取得した日に `verifiedAt` を付けて入力する。
- 取得していない値は入力しない。`status` は `verified`、`planned`(施行が確定)、`provisional`(独自仮定・検討中)のいずれか。
- `pnpm verify:regulations` が、メタデータの欠落、非HTTPSのURL、等級表の隙間などを検査する。
- 再配布権限と第三者の著作権は、データを追加するときに確認して下記に記録する。

## 検証

データを書いた担当とは別の検証担当が、一次資料を取得し直して全項目を突き合わせた。厚生年金の `effectiveTo` の根拠(標準報酬月額の上限は2027年9月に68万円、2028年9月に71万円、2029年9月に75万円)は、厚生労働省の資料で確認した。引上げ後の等級ごとの報酬月額の範囲は一次資料で確認できていないため、2027年9月以降のデータセットは登録していない。
