# 既知の制限と設計判断

`AGENTS.md` §12.1 に基づき、仕様の矛盾と未確定事項、およびそれぞれの扱いを記録する。

## 仕様の矛盾と判断

| 項目           | 矛盾・未確定                                                            | 判断                                                                                                              |
| -------------- | ----------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| 1ページ構成    | 単一ページと、計算方法・出典・FAQ・プライバシー・免責の公開が両立しない | `index.html` 1枚にアンカー付きセクションとして置く。リポジトリ内の `docs/` が一次の原稿                           |
| 金額の型       | 整数円とDecimalのどちらか                                               | 整数円。ライブラリは入れない。丸め規則は `docs/calculation-methodology.md` に定め、表示用丸めと計算用丸めを分ける |
| 健保組合       | 組合ごとの料率データを網羅できない                                      | 料率は利用者が入力し、結果に利用者入力と表示する                                                                  |
| 随時改定       | 簡易モードは即時反映の仮定                                              | 簡易モードでは掛金差が当該年の等級へ即時に反映されるものとし、結果に仮定として明示する。詳細モードはフェーズ6     |
| DC加入資格     | 勤務先の規程に依存し、アプリから確認できない                            | 利用者の申告とし、確定的に判定しない                                                                              |
| 年金額への影響 | 再評価率・乗率の検証済みデータがない                                    | データが `verified` になるまで老齢厚生年金の差額は「未対応」と表示する                                            |
| 制度数値       | 一次資料から取得していない値を埋めてはならない                          | 取得して検証した値だけを `verified` とし、他は欠落または `provisional`。`provisional` は精密計算に使わない        |

## 現時点の未対応

- 随時改定の詳細。受取時課税は一時金のみ試算し、年金受取の公的年金等控除は未対応。
- 一時金では短期退職手当等、特定役員退職手当等、障害者退職の100万円加算、過去4年・9年・19年内の退職手当等との勤続期間の重複控除、他の退職金との合算、確定申告での他所得との選択、2048年以降の税率変更は対象外。勤続5年以下は短期退職手当等に当たり得る。
- 拠出限度額は他制度なしの上限のみ警告として確認。加入資格、他制度掛金相当額控除と企業型DC/iDeCo区分は未対応。

```text
一時金 → 課税試算 / 年金受取 → 未対応
```

- 住民税の調整控除、森林環境税(国税1,000円。両制度で同額のため差額には影響しない)
- 扶養、住宅ローン控除などの未対応要因
- 老齢厚生年金の再評価率、従前額保障、2003年3月以前の期間

## 計算上の近似

- 制度は基準日時点の内容で全期間に固定する。2027年9月以降の標準報酬月額の上限引上げなど、将来の改正は反映せず警告を出す。
- 給与所得控除は速算表を使う。収入660万円未満では所得税法別表第五との間に数円から数千円の差が出うる(警告を出す)。
- 住民税の所得割は市町村分と道府県分を分けず、合計で100円未満を切り捨てる。最大100円の差が出うる。
- 住民税は前年所得課税の時差を考慮せず、同じ年の所得に課す。
- 健康保険の標準賞与額の年間上限は、シミュレーション年を単位に累計する(制度上は4月から翌3月)。
- 選択制DCは月給から拠出し、賞与は減額しない。賞与は年2回に均等に支払うと仮定する。
- 介護保険料は40歳以上65歳未満の年に年間を通じて課す。
- 既存資産の移換は新規掛金と独立して、入力された手数料と運用停止期間で比較する。移換の可否は確認できない。
- インフレ率は計算に使わない。現在価値は割引率のみで求める。

## 注意

本ツールは意思決定の補助であり、個別の金融・税務・年金の助言ではない。運用利回りはシナリオ上の仮定で、将来を保証しない。
