# 仮定

- 運用利回りは信託報酬控除前のシナリオ仮定で、将来の予測や保証ではない。
- 受給終了年齢は計算上の仮定で、寿命の予測ではない。
- 簡易モードでは、掛金による報酬の変化が当該年の標準報酬月額の等級へ即時に反映されるものとする。
- 比較は同額掛金を標準とする。同額の手取り負担での比較は拡張とする。
- 受取時課税を実装するまでは、運用資産を税引前評価額と表示する。
- 名目額と現在価値は別系列で扱い、混在させない。
- 健保組合とカスタム料率は利用者が労使合計を入力し、本人負担を折半する。事業主負担が大きい場合は本人料率の2倍を合計として入力する。

```text
利用者入力の合計料率 → 折半 → 本人負担
```

シナリオ比較はページのメモリ内にのみ保持し、再読み込みで消去します。
# 既存資産の移換

移換の可否は勤務先と運営管理機関に確認する。受取時課税は含めず、社会保険料の軽減は計上しない。

```text
既存資産 → iDeCoで継続 / 手数料控除 → 運用停止 → DCで運用
```
